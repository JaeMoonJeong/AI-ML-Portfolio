# Python Programming Fundamentals & Algorithm Practice

## 📖 Overview
This repository records the structured implementation of Python programming fundamentals, Object-Oriented Programming (OOP), and algorithmic problem-solving. 
The primary objective of this project is to build a solid technical foundation for **Data Engineering** and **AI Research**, focusing on logical code structure, efficient data handling, and modular system design.

## 🛠 Tech Stack
- **Language:** Python 3.12.12
- **Core Modules:** `datetime`, `csv`, `time`, `operator`

---

## 📂 Project Structure

### 1. Python Fundamentals
Focused on mastering control flow, data validation, and exception handling to ensure code stability and logic precision.

| Problem Name | Objectives & Key Concepts |
| :--- | :--- |
| **Print Multiples of Three** | Loop control logic and arithmetic operations. |
| **Remove Vowels** | String manipulation and filtering algorithms. |
| **Compare Numbers** | Type validation (`isinstance`) and conditional branching. |
| **Calculate Total/Even Sum** | Range control and accumulation logic. |
| **Divide Numbers** | **Exception Handling:** Implementing `try-except` blocks for runtime safety. |
| **String Compression** | Run-Length Encoding logic for data compression. |
| **Countdown Timer** | System time control using the `time` module. |

### 2. Objects and Classes (OOP)
Implemented Object-Oriented Programming concepts to create modular, reusable, and maintainable code structures.

| Problem Name | Objectives & Key Concepts |
| :--- | :--- |
| **Time Tracker** | Using `datetime` for state tracking and temporal calculations. |
| **Contact Book** | Object visualization using Magic Methods (`__str__`). |
| **Voting System** | Data mapping and management using **Dictionary** structures. |
| **Bank Account** | Transaction logic and object state management. |
| **Employee Manager** | Understanding **Class Variables** vs. **Instance Variables** and `@staticmethod`. |
| **Reservation System** | Centralized data aggregation across multiple instances. |

### 3. Advanced Challenges
Solved complex problems involving File I/O, mathematical algorithms, and comprehensive system design, simulating real-world engineering scenarios.

| Problem Name | Objectives & Key Concepts |
| :--- | :--- |
| **Time Management** | **File I/O:** Reading CSV data and implementing sorting algorithms with `operator`. |

| **Library Management System** | **Capstone Project:** Designed a comprehensive CRUD system managing interactions between Books, Members, and Rentals. |
